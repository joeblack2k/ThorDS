# Execution order

## G0 — State reconciliation

Confirm current HEAD, worktree, remotes, submodules, device, ROM ignore and latest status. Import this dossier without resetting or redoing completed milestones.

## G1 — Analog closeout

Close M6 using deterministic end-to-end input instrumentation, visual/game response and Original fallback. Do not leave human-feel wording as the only unresolved technical gate.

## G2 — M7 proof closeout

Close W01, W03, W04, W05, W06 and W20. Add deterministic debug-only instrumentation where the prior host-polling method cannot prove the requirement.

M7 remains Castle Garden scoped. Do not reintroduce Bob-omb as its exit gate.

## G3 — M8 product True Widescreen

Convert the probe into a profile-resolved normal feature with scene classifier, fallback, persistence, safe mode and full acceptance matrix.

## G4 — M10 actual ARM9 runtime

Implement core/JNI/config/telemetry/save-state behavior. Validate 100%, then ratios in ascending order. A minimum passing 125% closes the feature; higher ratios are per-ratio capabilities.

## G5 — M11 Enhanced UI

Expose exact-ROM controls and effective plan. Do not build a decorative shell before underlying feature state is real.

## G6 — M9 RA closeout

Wire the user-facing mode selection to the existing policy, complete runtime/network/device tests and validate conflict recovery.

## G7 — M13 real 60fps

Derive a reproducible game patch from community reference and decomp. Combine only with validated OC ratios. Prove unique updates and real-time behavior.

## G8 — M12 final stability/release

Run combination matrix, 60-minute soak, lifecycle, saves, security and final documentation.

## Parallelism

Allowed:

- read-only reviews;
- test generation for an already selected design;
- research that does not edit the same files;
- release inventory while a long soak runs.

Not allowed:

- two agents editing the same subsystem;
- starting M8 product mode before M7 proof contract is closed;
- starting 60fps product activation before actual ARM9 runtime telemetry exists;
- treating a side-agent plan as implementation.
