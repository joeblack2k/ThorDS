# Non-negotiables

1. **No ROM material in Git.** No `.nds`, `.srl`, ROM fragments, extracted Nintendo assets, save files or save states.
2. **No secrets.** No RA password, token, cookie, authorization header, keystore or device serial in source or evidence.
3. **No private captures in public history.** Store raw screenshots/video locally; commit only redacted aggregate text, JSON, CSV and approved diagrams.
4. **No force-push.** Preserve public history and both remotes.
5. **No reset to the dossier baseline.** Newer work is preserved.
6. **No duplicate subsystem.** Extend the existing profile, RA, renderer, settings and session architecture.
7. **No full-frame stretch called True Widescreen.** 2D/HUD distortion is a failure.
8. **No renderer counter called 60fps gameplay.** Unique game updates and timing must be measured.
9. **No requested value called ARM9 overclock.** Native effective behavior and telemetry must prove it.
10. **No silent RA downgrade.** Hardcore conflicts fail closed.
11. **No unsupported ratio exposure.** A ratio appears in normal UI only after its individual gate passes.
12. **No general-emulator regression.** Unknown ROMs and non-Thor devices retain safe upstream behavior.
13. **No third identical evidence attempt.** Improve instrumentation or method after two partial attempts.
14. **No completion claim from compile evidence alone.** Physical Thor proof is required for device-facing behavior.
15. **No direct achievement award.** Any online unlock is caused by normal gameplay and the existing runtime.
