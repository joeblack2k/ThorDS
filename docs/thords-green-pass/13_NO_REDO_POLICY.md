# No-redo policy

Do not repeat completed work.

## Already complete

- repository bootstrap and public source;
- exact rc5 source pin and toolchain;
- Thor panel roles, touch grid and lifecycle;
- separate package/product identity and safe mode;
- deterministic profile catalog/resolver;
- exact European SM64DS identity;
- AM64DS payload import and checksum;
- Slot-2 analog plumbing;
- radial normalization and camera hysteresis;
- RA policy foundation and pre-bootstrap plan gate;
- ARM9 requested/effective policy objects;
- read-only pause session status;
- structured Vulkan capture/probe foundation.

## Forbidden rewrites

- replacing melonDS with another emulator;
- moving back to a native SM64DS decomp port;
- replacing the profile engine with ad-hoc game checks;
- adding a second RA client;
- adding a second settings database;
- rewriting the Vulkan compositor from scratch before inspecting existing modes;
- replacing the analog patch with a new unknown patch;
- restarting M0-M5 for cleanliness.

## Required continuation style

Patch the missing seam, test it, commit it and continue. Refactor only when a concrete current defect requires it and tests preserve behavior.
