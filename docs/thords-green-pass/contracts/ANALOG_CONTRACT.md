# Analog contract

```text
Android physical/controller axis
→ radial normalization
→ exact profile session overlay
→ Slot-2 Analog addon
→ AM64DS game patch
```

- no global remapping for unrelated ROMs;
- no per-axis square deadzone;
- magnitude is clamped to 1 after radial processing;
- neutral is explicitly sent on release, pause, reset and session stop;
- right-stick camera owns only its synthetic D-pad source;
- a D-pad release is sent only when neither physical D-pad nor camera source holds it;
- Original removes curated code, Slot-2 addon and camera overlay;
- user cheats remain separate and cannot remove curated code accidentally.
