# Bounded handoff

Use only when a workstream must move to another primary model/session.

```text
Repository/branch/HEAD:
Worktree status:
Last green commit:
Active workstream:
Files changed:
Tests passed:
Tests failed:
Physical device state:
Private local artifacts:
Exact blocker:
Rejected approaches:
Next smallest action:
Do not reset/rewrite:
```

Do not hand off vague context or hidden uncommitted changes.
