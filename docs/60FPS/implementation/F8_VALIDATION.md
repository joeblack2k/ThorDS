# F8 — validation

## Deterministic replay

For each checkpoint:

1. load private state;
2. apply identical input timeline;
3. run Original;
4. run 60 FPS;
5. compare wall-time-normalized state;
6. repeat three times.

## Required checkpoints

- BOB spawn;
- Chain Chomp;
- mountain;
- King Bob-omb;
- Yoshi/Bob-omb;
- Tiny-Huge;
- water;
- flying;
- sliding;
- platform;
- cutscene;
- minigame.
