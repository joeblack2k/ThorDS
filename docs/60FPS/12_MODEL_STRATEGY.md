# Luna Max execution strategy

Use up to three bounded subagents.

## Subagent A — decomp and patch map

Read-only until a reviewed patch plan exists.

Deliver:

- cadence consumer inventory review;
- exact EU function/address/original-word map;
- initializer/reset map;
- patch strategy and risks.

## Subagent B — core and telemetry

Own only the core/JIT semantic monitor and ARM9 telemetry.

Deliver:

- actual dispatch hook;
- interpreter parity;
- tests;
- performance impact;
- public core commit proposal.

## Subagent C — independent validation

Read-only review of:

- patch guards;
- timing logic;
- test sufficiency;
- unsupported claims;
- ROM/privacy safety.

## Lead responsibilities

Luna Max must:

- inspect all subagent evidence;
- reproduce critical findings;
- own the profile/runtime patch;
- run physical Thor tests;
- decide gate status;
- commit and push.
