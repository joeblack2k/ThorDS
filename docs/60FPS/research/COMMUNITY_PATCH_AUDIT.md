# Community patch audit

## Known source

```text
Author attribution: gamemasterplc
Video: https://www.youtube.com/watch?v=yJXEAIOFcNU
Known target: USA revision 1.1
Distribution form: patched/xdelta-style community workflow
```

No public source code or European Action Replay words have been verified.

## Reported behavior

AYN Thor users reported:

- Chain Chomp slowdown;
- mountain slowdown;
- King Bob-omb speed changes;
- Bob-omb explosions in Yoshi's mouth;
- improved stability after removing only 60 FPS.

3DS users reported:

- enemies too fast;
- Bob-omb Battlefield half-speed;
- Tiny-Huge Island unbeatable;
- persistent lag despite overclock.

## Conclusion

The patch proves feasibility, not correctness.

It can serve as:

- an optional local binary-diff oracle;
- a bug-regression list;
- a clue about required CPU headroom.

It cannot serve as the EU release payload.
