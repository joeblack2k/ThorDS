# Physics parity

Measure in Original and 60 FPS over equal real time:

- standing gravity/fall duration;
- jump apex time and height;
- long-jump distance;
- full-stick run distance;
- swimming distance;
- flying turn/altitude behavior;
- slide acceleration/distance;
- moving-platform period;
- knockback duration;
- enemy travel/attack periods.

Prefer direct game-state telemetry over pixel measurements.

A visible smooth result is not enough when position/velocity diverges.
