# Audio tests

## Measure

- output sample rate;
- buffer fill;
- underrun count;
- music duration over fixed passage;
- sound effect pitch/duration;
- ARM7 timing;
- audio/video drift.

## Acceptance

- pitch unchanged;
- tempo unchanged;
- no doubled triggers;
- no persistent crackle;
- no stress-scene underrun increase beyond documented tolerance.

Do not correct audio by changing global playback speed.
