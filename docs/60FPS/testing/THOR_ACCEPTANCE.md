# Physical Thor acceptance

## Required witness

The connected AYN Thor must show:

- title screen state on both the upper and lower displays before input;
- correct upper/lower display roles;
- playable full-speed mode;
- correct input;
- no visible duplicated/half-speed systems;
- correct pause/settings status;
- stable sleep/wake.

## Human play witness

Automation can measure timing, but the owner must physically verify:

- responsive controls;
- normal-feeling speed;
- normal audio;
- no camera/input interference;
- stress scenes are enjoyable and not janky.

Record the witness separately from automated evidence.
