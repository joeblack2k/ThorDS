# Blocker policy

A blocker includes:

- exact failed command/test;
- exact current SHAs;
- evidence;
- methods already tried;
- why further autonomous progress is unsafe;
- smallest required action.

Not blockers:

- missing optional USA patch;
- first zero counter;
- first failed timing model;
- long compile;
- need for better telemetry;
- one stress-scene bug;
- incomplete documentation.

Use the two-attempt rule and improve the method.
