The existing ROM-details configuration screen now exposes a resolved ThorDS
profile status. Resolution uses the ROM header identity, the embedded
profile catalog, the existing hash-bound ProfilePreferencesRepository and
ProfileLaunchPlanner.

Displayed resolved values:

- profile id;
- exact/unsupported match classification;
- Original or Enhanced integrity;
- effective ARM9 percentage;
- effective RetroAchievements mode;
- effective widescreen mode.
- per-ROM Original/Thor Enhanced selection;
- per-ROM requested RetroAchievements mode selection.

the normal launch path after relaunch. The details screen shows an explicit
relaunch-required message after either profile control changes. No second
settings store or ROM database field was added.

the details screen or aborting validation leaves the persisted preference
unchanged.
