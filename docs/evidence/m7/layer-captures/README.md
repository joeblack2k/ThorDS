# M7 Layer Captures

The repository deliberately contains no gameplay frames, ROM-derived image
assets, or private ADB captures.

The Vulkan developer probe can render:

- high-resolution current 3D across the top presentation rectangle;
- packed top plane 1 only inside a centered 4:3 safe area.

This is a diagnostic for layer ownership, not a True Widescreen claim. Capture
metrics and scene classifications will be recorded as non-image data after a
valid local-ROM launch path and physical scene matrix are available.
