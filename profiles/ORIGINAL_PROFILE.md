# Profiel: Original

## Doel

Een veilige, transparante sessie zonder ThorDS-gamepatches.

## Instellingen

```text
runtime curated codes: none
Slot-2 analog: off unless game natively uses selected accessory
True Widescreen: off
presentation: native aspect
ARM9 overclock: 100%
60fps: off
user cheats: according to user and RA mode
rewind/save states: according to RA mode
```

Thor dual-screenlayout blijft toegestaan; dat is presentatie van de originele twee DS-schermen.

## RetroAchievements

- Off: toegestaan.
- Casual: toegestaan.
- Hardcore: eligible volgens existing emulatorregels.

Hardcore launch:

- reset/relaunch;
- no resume;
- no user cheats;
- no rewind;
- no load state;
- own User-Agent;
- visible indicator.

## Save

Voor SM64DS EU deelt Original de native save met runtime-only Enhanced.

## Safe mode

`Start in Safe 4:3 Mode` kiest dit profiel plus:

- renderer safe default;
- reset transient display overrides;
- no experimental shaders;
- no OC;
- no profile controller overlay;
- behoud save.

## General games

Onbekende ROMs gebruiken functioneel een general Original-achtig sessieplan met bestaande emulatorinstellingen.
